## Library landscape (checked, not assumed)

The issue named Clipper2 as the candidate. There is **no `clipper2` package on
PyPI**. What exists:

- `pyclipper` — bindings for Clipper **1**, not Clipper2.
- `pyclipr` 0.1.8 — maintained bindings for **Clipper2 2.0.1**. Chosen.
- `pyclipper2` 0.0.8 — exists but far less established.

Verified before planning that `pyclipr` installs on Windows/Python 3.13 and that
boolean difference correctly yields an outer ring plus an oppositely wound hole,
and that `execute2()` returns a `PolyTreeD` usable for containment.

Also verified up front, rather than discovering it late: **trimesh has no
self-intersection test.** That shaped the validation design.

## Spec issue found

Issue #1 asks for "a V-shaped concave notch with **two** reflex vertices". A
geometrically pure V yields exactly **one** — the apex. Both shoulders are
necessarily convex; making a shoulder reflex would require the material to
overhang the notch.

Caught by the first test written, before any implementation. Resolved by
truncating the apex with a 2 mm flat, which reads as a V and gives two reflex
vertices. Reasoning recorded in `docs/spike-01/geometry-spec.md`.

## Bugs found by tests during the session

Worth recording, because in each case the test caught something a render would
not have.

1. **Hole winding.** Rings are authored CCW, but Clipper2's NonZero fill rule
   needs holes wound opposite. Wrong winding silently *added* the island's area:
   B measured 1030 mm² instead of 966, and the band check reported 64 mm² of
   overlap. No error, no exception — just wrong numbers. Normalisation now lives
   in one place.
2. **Area filtered by a length tolerance.** Cleanup used the 1e-6 mm coordinate
   epsilon to filter slivers by *area*, so 8e-6 mm² of offset round-trip noise
   was reported as a manufacturability defect. Fixed with a separate,
   area-dimensioned threshold.
3. **A wrong test, not wrong code.** The first Clipper2 test summed *absolute*
   ring areas across a difference result and expected 96; the correct figure for
   absolute areas is 104 (100 outer + 4 hole). The adapter was right.

## The finding that matters

Manufacturability cleanup is a morphological opening, and applied naively it
**silently destroys shared boundaries** — it erodes B's copy of the C boundary
while C's own ring stays put. The geometry still renders, still slices, and still
passes every per-body manifold check. The failure is invisible in exactly the
artefacts you would use to look for it.

Cleanup now opens outer rings only and re-cuts holes from authoritative geometry.
Full write-up in `docs/spike-01/conclusion.md`.
